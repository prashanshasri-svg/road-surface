# road-surface
# Road Surface and Lane Geometry Analyzer

## Project Overview
A command-line classical Computer Vision project that analyses a forward-facing road scene. It combines region-of-interest selection, edge detection, Hough geometry, morphological segmentation and perspective transformation.

## Techniques
- Grayscale conversion
- Gaussian smoothing
- Sobel gradient magnitude
- Canny edge detection
- Region of Interest masking
- Probabilistic Hough Line Transform
- Morphological opening and closing
- Contour analysis
- Perspective transformation / bird's-eye view
- Quantitative image measurements

## Setup
```bash
python -m venv .venv
```
Windows:
```bash
.venv\Scripts\activate
```
Linux/macOS:
```bash
source .venv/bin/activate
```
Install:
```bash
pip install -r requirements.txt
```

## Command-line execution
```bash
python src/main.py --input data/road_scene.jpg --output results
```
Optional Canny thresholds:
```bash
python src/main.py --input data/road_scene.jpg --output results --low 45 --high 135
```

## Outputs
`01_grayscale.png`, `02_smoothed.png`, `03_gradient_energy.png`, `04_edges.png`, `05_road_roi.png`, `06_lane_segments.png`, `07_defect_candidates.png`, `08_defect_binary.png`, `09_bird_eye_view.png`, `10_bird_eye_edges.png`, and `summary.txt`.

## Interpretation
Hough segments are lane-like geometric candidates. Dark connected regions are only candidate surface defects; they are not guaranteed to be potholes or cracks. The bird's-eye image is generated by mapping an approximate road trapezoid to a rectangle.
